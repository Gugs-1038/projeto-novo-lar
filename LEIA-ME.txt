PROJETO NOVO LAR
Projeto acadêmico fictício de uma ONG de proteção animal.

ESTRUTURA
- README.md: documentação principal com visão geral, tecnologias, execução, testes e limitações.
- html/index.html: estrutura principal da SPA, página inicial e modelos das rotas.
- html/projetos.html: alternativa estática para projetos, voluntariado e doações.
- html/cadastro.html: alternativa estática para o formulário de voluntários.
- css/estilos.css: apresentação visual, adaptação para ecrãs menores e perfis de cor.
- js/menu.js: controla o submenu e o menu hambúrguer responsivo.
- js/formulario.js: valida os campos em tempo real, cria mensagens acessíveis e controla alertas e toast por delegação.
- js/componentes.js: cria os cartões de ajuda a partir de dados e de um único template HTML reutilizável.
- js/persistencia.js: guarda a última rota e um histórico curto de navegação no localStorage.
- js/integracoes.js: inicializa as máscaras de CPF, telefone e CEP com a biblioteca IMask.
- js/spa.js: intercepta a navegação, interpreta as rotas por hash e atualiza o conteúdo principal pelo DOM.
- FLUXO-GIT.md: registra as branches, os merges e a política de versionamento adotada no projeto.
- GESTAO-REPOSITORIO.md: registra retrospectivamente as tarefas, o marco da versão e as integrações equivalentes a pull requests.
- ACESSIBILIDADE.md: documenta os landmarks, os estados WAI-ARIA e a gestão de foco.
- CONTRASTE.md: documenta os modos claro, escuro, alto contraste e cores forçadas.
- validacao-contraste: contém o verificador local e o relatório de 25 pares cromáticos.
- package.json e package-lock.json: registam as dependências e os comandos da build.
- scripts/build.js: gera a pasta dist com HTML, CSS e JavaScript minificados.
- scripts/verificar-build.js: confirma referências, bundles, imagens e redução de tamanho.
- dist: versão de produção minificada e relatório de tamanho gerado pela build.
- imagens/animal-resgatado.jpg: imagem de compatibilidade.
- imagens/animal-resgatado.webp: versão otimizada da mesma imagem.
- capturas/componentes-feedback.png: visão conjunta de badges, alertas e toast.
- capturas/badges-nos-projetos.png: badges aplicados à página de projetos.
- capturas/alerta-no-formulario.png: alerta informativo aplicado ao cadastro.

COMO ABRIR
Abra o arquivo html/index.html em um navegador. As rotas #/inicio, #/projetos e #/cadastro são exibidas sem recarregar o documento.
Ao reabrir a aplicação sem informar uma rota, a última página válida é restaurada quando o armazenamento local está disponível.

OBSERVAÇÃO
Os nomes, o e-mail e o telefone apresentados são fictícios e foram usados apenas para fins acadêmicos.
O menu permanece visível como alternativa caso o JavaScript não seja carregado.
Os links conservam endereços HTML reais como alternativa caso o roteador da SPA não seja executado.
Na rota de projetos, os cartões repetitivos são gerados com cloneNode, textContent e DocumentFragment.
Por privacidade, nenhum dado pessoal preenchido no formulário é salvo no localStorage.
A biblioteca IMask 7.6.1 é carregada de forma assíncrona por CDN somente para orientar a digitação; a validação própria continua ativa e o formulário permanece utilizável se a conexão falhar.
Cada script local possui uma responsabilidade própria e fica isolado por IIFE; quando uma comunicação é necessária, utiliza uma API pública pequena e congelada ou o evento novolar:rota-renderizada.
O repositório adota main para versões estáveis, develop para integração contínua e branches feature, release e hotfix para trabalhos temporários.
Os modos escuro e de alto contraste acompanham as preferências do sistema operativo. O perfil de cores forçadas também respeita a paleta escolhida pelo utilizador.
A versão de produção é criada com npm run build. O esbuild gera bundles por página e minifica CSS e JavaScript, enquanto html-minifier-terser minifica o HTML. O relatório em dist/relatorio-build.txt regista a redução medida.
